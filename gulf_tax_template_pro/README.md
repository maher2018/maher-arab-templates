# Gulf Tax Compliance Pro

المنتج الرئيسي لقالب الضرائب في Arab Templates: واجهة عربية (RTL) تجمع ثلاث أدوات في صفحة واحدة.

## المكوّنات

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة: شريط عملات، لوحة أخبار، دردشة المساعد، أداة مسح الفواتير |
| `styles.css` | تنسيق عصري داكن يدعم RTL والتجاوب |
| `app.js` | منطق الواجهة (دردشة، أخبار، مسح، تصدير CSV/JSON) بلا أي مكتبة خارجية |
| `server.py` | خادم Flask: يقدّم الملفات ويوفّر المسح والمساعد والأخبار والعملات |
| `exchange_rates.json` | لقطة أسعار احتياطية تُستخدم عند انقطاع مصدر الأسعار |

## التشغيل

```bash
python -m pip install flask          # مرة واحدة
python gulf_tax_template_pro/server.py                 # http://127.0.0.1:5075
python gulf_tax_template_pro/server.py --port 5080 --open
```

## الواجهة البرمجية

| المسار | يشرح |
|---|---|
| `GET /` | الصفحة |
| `GET /api/health` | حالة الخادم والمحرّك |
| `GET /api/sample` | نص فواتير واتساب نموذجي (٣ فواتير) |
| `GET /api/news` | أخبار السوق من `data/market_news.json` |
| `GET /api/rates` | أسعار العملات مقابل الريال (حيّ + لقطة احتياطية) |
| `POST /api/scan` | مسح نص أو ملف `TXT/CSV` |
| `POST /api/assistant` | مساعد ضريبي محلي بقواعد معرفة خليجية |

## الربط مع المحلّل

`server.py` يستورد `parse_invoice` و`split_invoices` من `scripts/whatsapp_invoice_parser.py`، فيفصل الفواتير من نص واحد ويستخرج المورد والتاريخ والإجمالي والضريبة والنسبة ودرجة الثقة، ثم يعيد JSON فقط — لا يُخزَّن نص أي فاتورة على القرص.

## حدود معروفة

- **بلا OCR**: الصور وملفات PDF غير مدعومة؛ المطلوب نص أو ملف TXT/CSV. ربط OCR يحتاج مزوّدًا خارجيًا.
- **المساعد قائم على قواعد معرفة** لا على نموذج لغوي مدرَّب؛ الأجوبة ثابتة وموثوقة في حدودها ومكتوب صراحة أنها إرشادية.
- **الأسعار إرشادية** مقابل الريال السعودي من مصدر عام، مع لقطة محلية عند انقطاع الاتصال.
- لا مصادقة ولا قاعدة بيانات: هذا واجهة المنتج وأدواته، وربط الحسابات والدفع يأتي في طبقة الاستضافة.
