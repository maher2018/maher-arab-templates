# المساعد الذكي ثنائي اللغة — Smart Bilingual Assistant

المساعد الرسمي لمنصة Arab Templates: واجهة ويب واحدة (HTML/CSS/JS بلا مكتبات خارجية) تتبدّل فورًا بين العربية (RTL) والإنجليزية (LTR)، وتقدّم خدمتين:

1. **دعم العملاء والتوجيه**: اقتراح القالب المناسب حسب نوع النشاط والأولوية، شرح خطوات تشغيل كل قالب، والإجابة عن أسئلة الاستخدام والدعم.
2. **الاستشارات الضريبية والمحاسبية**: نسب ضريبة القيمة المضافة وحدود التسجيل ومواعيد الإقرار وحقول الفاتورة والغرامات والمعفاة/الصفرية في السعودية والإمارات ودول الخليج، مع أداة **تدقيق قيود الفواتير** التي تفحص الحساب والرقم الضريبي والتاريخ وتقترح القيد المحاسبي.

## التشغيل

```bash
python -m http.server 5082 --directory smart_bilingual_assistant
# ثم افتح http://127.0.0.1:5082/
```

أو افتح `index.html` مباشرة في المتصفح (كل شيء يعمل محليًا بلا خادم بيانات).

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | البنية: محادثة، شريط أسئلة سريعة، مواضيع ضريبية، كتالوج القوالب، نموذج التدقيق |
| `styles.css` | تنسيق عربي أولًا، متجاوب، مع أنماط LTR عند الإنجليزية |
| `app.js` | قاموس الترجمة، الواجهة، مسار التوصية، ومحرك التدقيق |
| `core.js` | قاعدة المعرفة (١١ موضوعًا) + تطبيع النص العربي ومحرك المطابقة وكشف الدولة وإجابات الدولة المخصصة |
| `tests.js` / `tests.html` | ٤٠ اختبارًا للأسئلة الشائعة (فصحى، لهجة خليجية، إنجليزية) وصفحة تشغيلها |

## الميزات

- **تبديل لغة فوري**: زر واحد يغيّر `dir`/`lang` وكل النصوص والأزرار والجداول، ويحفظ الاختيار في `localStorage` (`at_assistant_lang`).
- **قاعدة معرفة محلية**: لا يُرسل أي نص إلى خادم أو خدمة خارجية؛ كل الإجابات مكتوبة داخل `app.js` وقابلة للتوسيع من مصفوفة `INTENTS`.
- **مسار توصية تفاعلي**: سؤالان (النشاط ثم الأولوية) ثم توصية قالب مع السبب وخطوات الاستخدام.
- **كتالوج القوالب**: ٨ قوالب بخطوات عربية وإنجليزية، مع فتح مباشر للقالبين الموجودين في المستودع.
- **أداة تدقيق القيود**: تتحقق من `الصافي × النسبة = الضريبة`، `الصافي + الضريبة = الإجمالي`، صيغة الرقم الضريبي لكل دولة، تاريخ الفاتورة، ونسبة الضريبة الصفرية في قطر والكويت؛ ثم تعرض نسبة نجاح وقائمة فحوص والقيد المقترح (مدين/دائن) مع تصحيح مقترح عند الخطأ.

## المطابقة الذكية

لا تعتمد المطابقة على تطابق حرفي، بل تمر بالخطوات التالية داخل `core.js`:

1. **تطبيع** النص: حذف التشكيل والتطويل، توحيد `أ إ آ ← ا` و`ى ← ي` و`ة ← ه`، وحذف علامات الترقيم وتصغير اللاتينية.
2. **تجزئة** إلى كلمات مع تجريد السوابق الشائعة (`وال، بال، كال، فال، لل، ال`) للوصول إلى الجذر التقريبي.
3. **مطابقة العبارات**: عبارة كاملة داخل السؤال تُعطي وزنًا أعلى من كلمة مفردة، ومطابقة جزئية للعبارة تتطلب كلمتين معنويتين على الأقل حتى لا يطابق «كيف الحال» موضوع «كيف أشغّل».
4. **أوزان تعزيز** لكل موضوع (boost) تُطبَّق عند وجود جذر مميز مثل `قيود` أو `غرام` أو `register`.
5. **كشف الدولة** من أسمائها ومدنها وعملاتها مع تجاوز السوابق (`بالإمارات`، `بالرياض`، `بالبحرين`)، ثم عرض إجابة مخصصة لتلك الدولة بدل جدول عام.

أمثلة مدعومة الآن: «وش نسبة الضريبة بالإمارات؟»، «هل أحتاج أسجل؟»، «لازم نسجل ولا لا؟»، «ايش الفرق بين الصفريه والمعفاه؟»، «ابغى اكلم احد من الدعم»، و«what's the VAT in Dubai?» و«I need to talk to a human».

## الاختبارات

```bash
# في المتصفح (يعمل دائمًا)
http://127.0.0.1:5082/tests.html

# أو من الطرفية عند توفر Node
node smart_bilingual_assistant/tests.js
```

`tests.js` يحتوي ٤٠ حالة: فصحى، صيغ خليجية حرة، إنجليزية، وحالتان يجب أن تُعيد «لا أعرف». تقرأ الصفحة النتائج من `runFaqTests()` وتعرض المتوقّع والفِعلي والدولة والدرجة، وتفشل إذا لم تطابق النية أو الدولة.

## إضافة موضوع جديد

أضف عنصرًا إلى `INTENTS` في `core.js` مع `id` فريد:

```js
{
  keys: ["كلمة", "keyword"],
  answer: { ar: "الجواب بالعربية…", en: "The answer in English…" },
}
```

ولإضافة موضوع إلى شبكة «مواضيع ضريبية» أضف مفتاحًا إلى `TOPICS` مع نصوص `topic.<key>` و`topic.<key>.sub` في القاموسين.

## حدود

- الإجابات إرشادية مبنية على قواعد مكتوبة وليست استشارة ضريبية معتمدة، ولا تُحدَّث تلقائيًا عند تغيّر الأنظمة.
- أداة التدقيق تفحص الاتساق الحسابي والصيغ، ولا تتحقق من وجود الفاتورة في منظومة الهيئة.
- لا يوجد تسجيل محادثات أو حسابات مستخدمين؛ الحالة كلها في الصفحة.

## English summary

A dependency-free bilingual (AR/EN, RTL/LTR) assistant for Arab Templates: it recommends a template from an eight-item catalogue with setup steps, answers Gulf VAT and accounting questions from a local eleven-topic knowledge base, and includes an invoice-entry auditor that checks VAT arithmetic, tax-number formats, dates and zero-rated countries, then suggests the journal entry. Everything runs client-side; the language choice is stored in `localStorage`.
