- خطوات مرقّمة وقابلة للتنفيذ بلا خبرة تقنية سابقة.
- لا تُدرج أي مفتاح API أو كلمة مرور حقيقية؛ استخدم أسماء المتغيرات فقط.
- أضف قسم «استكشاف الأخطاء» لكل دليل، وقسمًا إنجليزيًا موجزًا في النهاية.
