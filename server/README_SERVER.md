# تشغيل الخادم (اختياري)

الموقع كامل يعمل كملفات ثابتة، لكن هذه الميزات تحتاج الخادم:

- إصدار وحفظ الفواتير الضريبية، والسجل، والإقرار الضريبي.
- فحص فواتير الموردين من صورة (OCR) ومسح نص واتساب دفعة واحدة.
- محاكي التفتيش، التنبؤ بالسيولة، إرسال الفواتير بالبريد.

## التشغيل

1. ثبّت Python 3.10+ إن لم يكن مثبتًا.
2. `pip install flask` (أو `pip install -r requirements.txt` إن وُجد).
3. شغّل `START_SERVER.bat` أو نفّذ: `python server.py --port 5075`
4. افتح: http://127.0.0.1:5075/

لدمج الصفحة الثابتة مع الخادم انسخ ملف `gulf_tax_template_pro/index.html` إلى جوار الخادم، فالخادم يقدّم نفس الملفات من مجلده.
